# Hands-On 1 — First Web API using .NET Core

Covers:
- RESTful WebAPI / Web API / Microservice concepts (see the original doc's objectives)
- HttpRequest & HttpResponse, action verb attributes ([HttpGet], [HttpPost], [HttpPut], [HttpDelete])
- HttpStatusCodes via ActionResult types (Ok, BadRequest, etc.)
- A first Web API with Read/Write actions
- Configuration files: `Program.cs` (modern minimal-hosting equivalent of Startup.cs
  + Route.config/WebAPI.config from .NET Framework), `appsettings.json`, `launchSettings.json`

## What's here

`Controllers/ValuesController.cs` — the classic scaffolded "ValuesController"
with GET/POST/PUT/DELETE action methods, generated by
`dotnet new webapi -controllers` and then filled in with matching methods for
every action verb, exactly like the old VS "Web API with Read/Write actions" template.

## Run it

```bash
dotnet restore
dotnet run
```

Open `/swagger` (default template includes Swagger already) or hit
`GET https://localhost:<port>/api/values` in a browser and confirm you get
`["value1","value2"]` back.

> Note: written without nuget.org access in this sandbox — please
> `dotnet restore && dotnet build` yourself before pushing.
